# 僵尸资源信息表

- 普通僵尸模型默认使用代码名字查找 `ReplicatedStorage.ItemModels`；如果配置了 `ModelName` 则优先使用 `ModelName`。
- `DancingZombie` 如果找不到同名模型，服务端会回退使用 `Zombie` 模型。
- 当前僵尸配置里没有 `IconId`、`ImageId` 这类图标字段，所以图标 ID 统一记为 `-`。
- 配置中没有填写的动作资源记为 `-`。
